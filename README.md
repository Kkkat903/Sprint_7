Sprint_7 — API-тесты сервиса «Яндекс Самокат»

Описание проекта
Проект содержит автотесты API учебного сервиса «Яндекс Самокат». Тесты проверяют создание курьера, авторизацию курьера, создание заказов и получение списка заказов.

Технологии
- Python
- Pytest
- Requests
- Allure Pytest
- Faker

Проверяемые сценарии
1. Курьеры (test_courier.py)
    - Создание курьера.
    - Проверка создания курьера с уже существующим логином.
    - Проверка создания курьера без обязательных полей.

2. Авторизация (test_login.py)
    - Авторизация курьера.
    - Проверка авторизации без обязательных полей.
    - Проверка авторизации с некорректными данными.
    - Проверка авторизации несуществующего пользователя.

3. Заказы (test_orders.py)
    - Создание заказа с разными вариантами цвета самоката.

4. Список заказов (test_orders_list.py)
    - Получение списка заказов.
